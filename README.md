# House-Sale-Condition-Prediction
## Project Overview
This project uses machine learning to predict the sale condition of houses based on different property features.
## Dataset
The dataset contains information about houses and their features used for predicting the sale condition.
## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook
## Machine Learning Model
Gaussian Naive Bayes: Achieved 70% training accuracy and 66% testing accuracy, show low performance on both training and testing data.
Logistic Regression: Achieved 91% training accuracy and 85% testing accuracy, showing good performance with slight overfitting.
SVM: Achieved 92% training accuracy and 86% testing accuracy, showing good performance with slight overfitting.
Decision Tree: Achieved 100% training accuracy and 72% testing accuracy, indicating significant overfitting.
Random Forest: Achieved 97% training accuracy and 81% testing accuracy, indicating overfitting.
## Project Steps
1. Data loading
2. Data preprocessing
3. Feature selection
4. Model training
5. Model evaluation
6. Prediction
